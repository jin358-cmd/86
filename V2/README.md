# V2 — GVG OS Global Platform

Saved snapshot of the current GVG OS design (light cyberpunk entry + marketplace platform).

## Flow

`INITIALIZE` → Boot → Wear → Login → City → World → Dashboard

## Features

- Sci-fi cosmos start gate with text-centered satellite orbits
- Light cyberpunk platform UI
- Two-layer comet cursor (burst + drag trail)
- Light flowing tech BGM / SFX loop
- First-person chapter node transitions
- Product Center + Marketplace with generated item photos
- Phase architecture pages + Admin OS

## Run

```bash
cd V2
npm install
npm run dev
```
