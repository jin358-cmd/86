# Beta1 — GVG OS Beta 第1版

主動開發線。以 V2 商城／平台為基底，標註為 **Beta 1.0**，供內測與持續迭代。

V1 / V2 資料夾保留為歷史版本預覽，不再作為本線開發來源。

## Beta 第1版範圍（Phase 1）

- 沉浸式入口（Start Gate / Initialize）
- 電影級章節流：Boot → Wear → Login → City → World → Dashboard
- 品牌落地頁：Company、Why GVG
- 平台模組骨架（後續 Phase 持續開放）

## 本機執行

```powershell
cd F:\@Jin\86-main\Beta1
git pull
npm install
npm run dev
```

Open `http://localhost:3000`.
